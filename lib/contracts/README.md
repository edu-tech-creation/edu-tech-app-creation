# lib/contracts

This directory holds generated files for the `EduCredential` smart contract.

## Files

| File | Description | Generated by |
|------|-------------|--------------|
| `EduCredential.abi.json` | Contract ABI for frontend use | `pnpm chain:export-abi` |
| `deployments.json` | Per-chain deployment addresses | `pnpm chain:deploy:*` |

## Quick start

```bash
# 1. Compile the contract
pnpm chain:compile

# 2a. Start a local Hardhat node (keep this running in a separate terminal)
pnpm chain:node

# 2b. Deploy to the local node
pnpm chain:deploy:local

# 3. Export the ABI so the Next.js app can import it
pnpm chain:export-abi
```

## Sepolia testnet

Add these to `.env.local`:

```
SEPOLIA_RPC_URL=https://sepolia.infura.io/v3/<your-project-id>
DEPLOYER_PRIVATE_KEY=0x...
```

Then run:

```bash
pnpm chain:deploy:sepolia
```
